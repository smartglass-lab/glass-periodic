# グラス周期表 — Glass Periodic

Meta Ray-Ban Display 用の**周期表**。118元素の表を ↑↓←→ で歩くと、その元素の記号・名前・原子番号・原子量・分類・周期と族・常温での状態・ひとことメモ（「青色LED・体温でとける金属」など）が下のカードに即座に出ます。タップで詳細（電子配置つき）を開き、←→ で原子番号順にめくり読み。詳細から「記号クイズ（10問）」で記号⇄名前を覚えられます。分類は11色で塗り分け。依存ライブラリなし・オフライン動作。

- **ライブURL**: https://glass-periodic.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / DOM / 静的サイト）

## 特徴

- **タップとD-padだけで使える** — ←→↑↓＝表の上を移動（空きマスは飛ばし、端でループ）、タップ＝詳細を開く
- **118元素を1画面に** — 18列×7周期＋ランタノイド・アクチノイド行。カーソル位置の元素は拡大して光る
- **見ながら学べる下部カード** — 移動するたびに 記号／名前（和・英）／原子番号／原子量／分類／周期・族／常温の状態／ひとことメモ を更新
- **詳細オーバーレイ** — 電子配置（殻ごとの電子数）を追加表示。←→ で前後の元素へめくれるので、原子番号順に通し読みができる
- **記号クイズ（10問）** — 「この記号の元素は？」と「この元素の記号は？」を交互に4択で出題。正解すると自己ベストを保存（localStorage）
- **色の意味** — アルカリ金属／アルカリ土類金属／遷移金属／その他の金属／半金属／非金属／ハロゲン／貴ガス／ランタノイド／アクチノイド／未確認 の11分類を凡例で確認
- **加算式ディスプレイ向けの絵** — 純黒の背景は透明。セルとカードは暗いパネル色で視界に浮かぶ
- **画面内で完結する操作** — 戻るジェスチャー不要。オーバーレイは「◀ とじる」、クイズは結果画面の「◀ 周期表にもどる」で戻れる

## 操作方法

| 画面 | 操作 |
|------|------|
| 周期表 | ←→↑↓＝カーソル移動（下のカードが追従）、タップ＝詳細を開く |
| 詳細 | ←→＝前後の元素をめくる、↑↓＝ボタン選択、タップで「◀ とじる」／「❓ 記号クイズ」／「🎨 色の意味」 |
| 色の意味 | タップで「◀ とじる」 |
| クイズ | ↑↓＝4択をえらぶ、タップ＝回答（10問） |
| 結果 | ↑↓でえらび、タップで「🔁 もういちど」／「◀ 周期表にもどる」 |
| PC確認用 | Escape でオーバーレイ／クイズを閉じる（グラスの戻るジェスチャーは使用不可のため補助のみ） |

`?demo=1` を付けると保存された位置・自己ベストを読まず、保存もしません（デモ録画用）。

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E5%91%A8%E6%9C%9F%E8%A1%A8&appUrl=https%3A%2F%2Fglass-periodic.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラス周期表`、URL `https://glass-periodic.vercel.app` を入力。
